**The app now lives at [vault.niclaslindstedt.se](https://vault.niclaslindstedt.se/).**
Deploys moved from the GitHub Pages project path to the custom domain, with
three coexisting release channels: the latest release at `/`, current `main`
at `/preview/`, and an on-demand branch build at `/branch/`. Each channel
installs as its own PWA with a distinct name and icon tile.
