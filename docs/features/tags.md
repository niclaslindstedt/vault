# Tags

Tags are free-form labels — many per document, any text ("2024",
"House move", "Warranty"). Where categories and folders partition the vault,
a tag **binds documents across every category and folder**: selecting a tag
in the side menu shows everything carrying it — the receipt in _Receipts_,
the contract in _Legal_, the policy in _Insurance_ that all belong to the
same house move.

The tag field in the editor suggests the tags already used across the vault
(typeahead) but never limits you to them. Tags are deduped
case-insensitively — `warranty` and `Warranty` are the same tag, displayed
with the first-seen casing.

Tag text is part of the search corpus, so a query matches tagged documents
too.
